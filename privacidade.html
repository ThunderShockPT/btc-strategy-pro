Privacidade e dados guardados

Esta página descreve o funcionamento da Beta Demo pública. Não representa uma política definitiva de um serviço com contas de utilizador. Antes do lançamento com contas, faltam identificar publicamente o responsável pelo tratamento e disponibilizar um contacto privado para pedidos de privacidade.

1. Que dados ficam neste dispositivo?

Os projetos, parâmetros de simulação, registos manuais e respetivas notas são guardados através do armazenamento local do navegador (localStorage). Na Demo, o utilizador não precisa de indicar o nome nem o email para utilizar estas funções.

A aplicação também pode guardar cópias dos seus ficheiros estáticos no navegador para funcionar sem Internet. Limpar os dados da aplicação, do navegador ou desinstalar a PWA pode eliminar os projetos locais.

2. Os projetos são enviados para uma conta online?

Não, nesta versão. O registo e o login cloud estão desativados. Existe uma integração técnica com o Supabase preparada para uma fase posterior, mas ainda não autoriza contas públicas. Não introduzas credenciais de corretoras ou informações que não queiras guardar neste dispositivo.

3. Serviços de alojamento

O site é alojado no GitHub Pages. O prestador de alojamento pode tratar dados técnicos de pedidos, como endereços IP e registos de acesso, de acordo com as suas próprias políticas. A aplicação Demo não inclui, no seu código, um sistema próprio de análise de visitantes.

4. Exportar e apagar os projetos

Em Conta / Projetos, utiliza «Exportar backup JSON» para guardar uma cópia dos teus dados. O ficheiro contém históricos e notas, por isso mantém-no privado. Usa «Apagar dados locais» para eliminar os projetos neste navegador, com dupla confirmação. A aplicação cria depois um projeto Demo inicial vazio para continuar a funcionar.

Apagar projetos neste navegador não apaga uma cópia JSON guardada em Downloads, noutro dispositivo ou num backup teu.

5. Informações de contacto e direitos

Para comunicar erros gerais, utiliza os pedidos de suporte no repositório. Não publiques dados pessoais, emails privados, passwords ou tokens num pedido público do GitHub. Será disponibilizado um canal privado antes de serem ativadas contas de utilizador. A presente informação será revista nessa fase para incluir responsável, bases legais, prazos de retenção e o procedimento de exercício de direitos.
